Few promises on the sheet.

Every tight dimension is a promise someone has to inspect.

A drawing that says "make it fit" is a conversation. A conversation does not tell a machinist where to hold the part, and it does not tell a board house which hole is allowed to wander. Daniel Rodgers names the fit the mechanism needs, and he leaves the rest loose so the factory is free where freedom is cheaper.

Open is a decision. It is not a blank someone forgot.

Name the fit

A shaft and a hole that must turn. A clip that must pass a rib and then hold. A face that must meet another face and stay there. Those features get a tolerance, a datum, and a view that shows them first. The length of a handle, the edge of a lightening pocket, the position of a mark: those can stay open. Tightening them spends money and hides the feature that actually carries the mechanism.

A drawing with every dimension tight has not decided what matters. The shop will either chase all of them, or quietly choose which ones to ignore. He would rather make that choice on the sheet, where the prototype can still inform it.

The first view is the view a machinist reaches for.

What the prototype is allowed to change

The first physical version exists to find the dimension that was wrong. Maybe the knuckle gap binds. Maybe the beam will not pass the rib. Maybe a hole for a connector collides with a wall that looked fine in the model. He changes that dimension in the file. He writes, next to the feature, what the object taught.

A lesson that stays in a notebook, while the old model goes out, is a lesson the factory will not see. The file and the object have to agree before the package leaves. He sets them side by side. Where they disagree, he changes the file or he changes the object.

The old file is a false instruction once the part has moved.

Letters, on a study

The drawings in this set use letters. A is the fit that matters. B is a dimension left open. There is no measured number on them, because a number belongs on the sheet for a real part, after someone has measured the part that taught the lesson. A sample page that invents a thousandth of an inch is pretending to be a job.

On a circuit, the same rule holds. A topology study shows the path: source, switch, resistor, load. Values go on the schematic after the bench, when they are the values he probed. A resistor that "should be about right" is not a callout a board house can buy.

A is the fit. B is free. The number comes later, from the part.
