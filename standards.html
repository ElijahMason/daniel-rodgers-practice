Sheet 04

Four standards, kept in the open.

These are the rules Daniel Rodgers works by. They decide what gets built, what gets drawn, and when a package is ready to leave.

  1. A prototype answers a question.

    Write the question before the build. "Will this latch clear the rib at full travel?" is a question. "Make a prototype" is a wish. He builds the feature that holds the doubt, and he stops when you can point at an answer. An answer that kills the idea still counts. A model that only looks finished does not.

  2. Drawings a machinist or a board house can use.

    Put the view a machinist reaches for first. Name the datums. Dimension the fit that matters, and leave cosmetic faces alone. For a circuit, draw what the board house will fabricate: schematic, outline, holes, stack, and the connector the rest of the product already has. If a reader has to guess which face is current, the sheet is not done.

  3. Materials chosen on purpose.

    Pick a material for the question, and pick again for the factory. A printed polymer is the right study when you are learning a snap, a clip, or a volume you can hold. It is the wrong production call when the part sees heat, a thread that must hold, or a load that creeps. Name the production material even when the study was printed in something else. The study and the production part may differ. The drawing has to say which one it describes.

  4. The file and the object agree.

    Measure the feature the drawing calls out. If the object and the file disagree, change the file or change the object before the package goes out. A lesson that stays in a notebook, while the old model goes to the factory, is a lesson the factory will not see. He sends the version the part already taught.
