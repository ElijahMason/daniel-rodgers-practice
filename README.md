# Daniel Rodgers

Static pages for Daniel Rodgers, custom hardware engineering. This branch is the anodized poster.

## Contact address

Open `js/site.js` and set `CONTACT_EMAIL=""`. Put a real address between the quotes to show a mailto link on the ticket page. Leave the quotes empty and the page only assembles the brief and copies it.
