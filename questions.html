Poster Studies Questions Separation Ticket

One doubt, then a build.

Daniel Rodgers makes the first physical version so a question can be answered in the hand, or on the bench. Concept models, mechanical prototypes, electrical prototypes, and printed studies are different tools for that job. He stops when the doubt has an answer, including an answer that kills the idea.

  1. What moves, and what stays.

    Point at the joint before a model exists. A concept model is there so two people can mark the same surface. If the model is too precious to mark, it has already missed its job.

  2. Which doubt the build may answer.

    Will the latch clear the rib. Does the shaft bind when the bracket flexes. Is the return path real. He builds the feature that holds that doubt and keeps the rest plain, so the answer stays visible.

  3. Which material is evidence.

    A printed shape can teach a finger clearance, a clip, or a hinge gap. Heat, creep, and a thread that must hold need the material the factory will actually run. He writes both names when they differ. A batch of plastic for sale is a different trade.

  4. What the factory will read.

    A machinist needs the fit. A board house, the shop that fabricates the bare board, needs the schematic that was probed. Both need the file to match the object. That package is the design-for-manufacture handoff.

Make one that a factory can read.
