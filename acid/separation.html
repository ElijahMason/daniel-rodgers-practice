Sheets a factory can read apart.

He splits the handoff the way a printer keeps films apart, so each sheet carries one kind of fact. The work is the sheets and the files. Running a print shop is a different trade.

Cyan, geometry

The shape that works.

Views of the mechanism or the board outline. Datums that locate the part. Dimensions on the fits that matter. Loose edges stay loose, so the shop is free where freedom is cheaper. File names match the sheet titles.

Magenta, the lesson

What the build changed.

The question the prototype asked, and the answer the object gave. If a latch moved, the sheet says so next to that feature. If a resistor value moved on the bench, the schematic that leaves is the one he probed, not the sketch from the night before.

Yellow, material

Chosen on purpose.

The study material, the production material, and the reason they differ when they differ. A metal and its condition. A polymer and the way it will be formed. A board stack and the connector the enclosure already expects. A stand-in part is labeled as a stand-in.

Then the file meets the object.

He sets them side by side before the package goes out. Where they disagree, he changes the file or he changes the object. A factory should not have to pick a winner.
