Sheet 03

Drawings a factory can follow.

The handoff is the package a manufacturer builds from. Drawings and files agree with the object that was just in the hand. Daniel prepares that package for mechanisms and for circuits.

For a machinist

A machinist needs views that show the working geometry, datums that locate the part, and dimensions on the fits that matter. Loose features stay loose, so the shop is free where freedom is cheaper. A drawing that tightens every edge has not decided what the mechanism needs.

The material callout names a process. A metal and its condition. A polymer and the way it will be formed. A note records what the prototype changed, in plain language, next to the feature that moved. File names match the sheet titles, so the model, the drawing, and the object can sit side by side.

For a board house

A board house is the shop that fabricates the bare board. It needs a schematic with the values fitted on the bench, a board outline, the holes, and the stack the house builds. The note says what the circuit had to prove, and which choices were temporary.

A net the house cannot read is not a handoff. The connector on the drawing is the connector the enclosure already expects. If the prototype used a stand-in, the sheet says so, and it names the part the factory should load.

The file and the object

He sets the file next to the object before the package goes out. If a dimension disagrees, he changes the file or he changes the object. The factory should not have to pick a winner between a model and a part.

That check is the last step of the prototype, not a separate courtesy. The first physical version has done its job only when a stranger with a machine can follow the sheets.
